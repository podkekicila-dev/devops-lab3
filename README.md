# devops-lab3

Локальное изменение: строка отредактирована локально.
Удалённое изменение: строка отредактирована через веб-редактор GitHub.

## FEAT-123

Изменение, добавленное в ветке FEAT-123.

## Как воспроизвести

Лабораторная П03 (практика git) выполнена в этом репозитории. Демонстрируются:

1. Локальный репозиторий, первый коммит, привязка к пустому удалённому репозиторию, `git push`.
2. Конфликт слияния: локальная и удалённая (веб-редактор) правки одной строки → `git push` отклонён → `git pull` → конфликт → ручное разрешение → коммит → `git push`.
3. Ветка `FEAT-123`, `git push -u origin FEAT-123`, слияние в `master` (fast-forward).

История: `git log --oneline --graph --all`.
